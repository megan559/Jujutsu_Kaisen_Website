Welcome to the **Jujutsu Kaisen Website** repository! This project is a fan-made website dedicated to the popular anime and manga series *Jujutsu Kaisen*. It showcases information about the series, its characters, episodes, and more.

## About

This project is designed to provide fans of *Jujutsu Kaisen* with an interactive and visually appealing online experience. Whether you're new to the series or a longtime fan, the website offers exciting content to explore.

---

## Features

- **Character Profiles**: Learn about your favorite characters.
- **Episode Guides**: Browse through summaries of episodes.
- **Responsive Design**: Fully functional on both desktop and mobile devices.
- **Stylish UI**: Designed with an aesthetic inspired by *Jujutsu Kaisen*.
